# Portfolio — Irene Pascual Albericio

Sitio estático de una sola página, sin dependencias ni build. Para verlo:

```bash
cd portfolio
python3 -m http.server 8000
# abrir http://localhost:8000
```

También puede desplegarse tal cual en GitHub Pages, Netlify o Vercel apuntando a esta carpeta.

Estructura:
- `index.html` — contenido
- `css/style.css` — estilos
- `js/main.js` — animaciones (grafo de fondo, terminal, scroll reveal)
- `assets/CV_Irene_Pascual.pdf` — CV descargable desde el botón del header
